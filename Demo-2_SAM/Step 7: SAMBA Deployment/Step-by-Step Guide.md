# Step 6: SAMBA Deployment
This step will demonstrate how to access the OAC instance support the SAM Business Analytics Dashboards. 

1. Download DVA file
   
   https://github.com/HairyQ/Redhat-Summit/blob/main/Demo-2_SAM/Step%207%3A%20SAMBA%20Deployment/Aircraft%20Event%20and%20Anomaly%20Dashboard.dva

2. Log into Oracle Analytics Cloud instance
3. Click 3-dot button in top-right corner
4. Click Import Workbook/Flow
5. Select DVA file and Click Import
