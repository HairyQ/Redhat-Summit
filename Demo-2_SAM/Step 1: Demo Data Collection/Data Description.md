# Demo 2: Demo Data Description
This dataset consists of dummy telemetry data consisting of 14 variables. Each variable is associated with an individual virtual IoT device on a turbine engine. The devices are

| Variable                             | Unit           |
|--------------------------------------|----------------|
|1. Low-Pressure Compressor Outlet     |Temperature (R) |
|2. High-Pressure Compressor Outlet    |Temperature (R) |
|3. High-Pressure Turbine Outlet       |Temperature (R) |
|4. Low-Pressure Turbine Outlet        |Temperature (R) |
|5. Bypass-Duct                        |Pressure (psi)  |
|6. Fan Inlet                          |Pressure (psi)  |
|7. Fan Outlet                         |Pressure (psi)  |
|8. Low-Pressure Compressor Outlet     |Pressure (psi)  |
|9. High-Pressure Compressor Outlet    |Pressure (psi)  |
|10. Burner Outler                     |Pressure (psi)  |
|11. Low-Pressure Turbine Outlet       |Pressure (psi)  |
|12. Physical Fan                      |Speed (rpm)     |
|13. Physical Core                     |Speed (rpm)     |
|14. Fuel Flow                         |Flow (pps)      |
