# Step 6: IBM Maximo Data Configuration
IBM Maximo is an enterprise asset management platform that helps organizations track, manage, and maintain physical assets across their lifecycle.

In this demo, Maximo Events Management module serves as the endpoint where AI-summarized incident reports are automatically logged as structured records, enabling streamlined maintenance workflows and faster response to operational issues.


IBM Maximo log in information will be provided by the IBM team when a demo instance is launched. Note, it is likely that the domains are not publicly registered, so you will need to add the IP/Domains to your local hosts file in order to access the UI. These details will be provided by the IBM team.

For this demo, we will be mapping our JSON Payload generated by our Python-based Function to IBM Maximo Events Management module. Certain data elements in Maximo are reference data fields or controlled values, and must be pre-inputted into Maximo. This section will demonstrate how to do that.

NOTE: The following steps apply to the 'ASRS_New_Data' data set. If you download new data, you will need to perform the same actions with the values associated with your data. Some of the data in the ASRS_New_Data has been pre-edited to fit IBM Maximo object structures. Those edits are noted in the steps below.

## Person
This will describe how to create new people in Maximo. 
  - Source variable from our ASRS dataset is 'Person 1_Function'
  - Target variable in Maximo is 'People'

Step-by-Step Walkthrough:
1. Log into IBM Maximo and find the Search tab in the top left 
2. Search for 'People' and click on 'People'
3. Click 'New Person' on the left menu labeled 'Common Actions'
4. Enter 'FIRST OFFICER' in the 'Person' field in the form
     
     - Ensure this is in ALL CAPS
5. Click the Save button in the top right
6. Repeat the process for the following People

     - 'PILOT'
     - 'CAPTAIN'
  
NOTE: If you are using newly downloaded data, you will need to ensure that the values for 'Person 1_Function' are in all caps. You can accomplish this via the UPPER() function in Excel.
  

## Make/Model
This will describe how to create new aircraft models in Maximo.
  - Source variable from our ASRS dataset is 'Aircraft 1_Make Model Name'
  - Target variable in Maximo is 'Models'
    
Note: This data will not actually be included in the JSON payload posted to Maximo, but is necessary to submit an Aircraft MSN ID. 


Step-by-Step Walkthrough:
1. Log into IBM Maximo and find the Search tab in the top left 
2. Search for 'Models' and click on 'Models'
3. Click 'New Model' on the left menu labeled 'Common Actions'
4. Enter 'A321' in the 'Model' field in the form
5. In the 'Code' variable, click the magnifying glass icon and select 'AIRCRAFT'
6. In the 'Label System' variable, click the magnifying glass icon and select 'ATA'
7. Uncheck the Pill icon labeled 'Weith and Balance?'
8. In the section 'Labels for XXX', click the mangnifying glass under 'Label System' and select 'ATA'
9. Click the Save button in the top right
10. Once saved, click on  the 'Configurations' tab on the top of the form
11. In the 'Configurations' section, click the 3 Dot icon on the right-side of the line with your new model and 'Base Configuration'
12. Drop down the variable labeled 'New Status', select 'Active' and click 'OK'
13. In the 'Configuration Node' section, uncheck the Pill icon labeled 'Abstract?'
14. Click the Save button in the top right
15. Repeat the process for the following Models

     - 'A319'
     - 'A320'
    


## MSN ID
This will describe how to create new aircrafts in Maximo.
  - Source variable from our ASRS dataset is 'Aircraft 1_MSN ID'
  - Target variable in Maximo is 'New Aircraft'
    
Step-by-Step Walkthrough:
1. Log into IBM Maximo and find the Search tab in the top left 
2. Search for 'New Aircraft and Equipment' and click on 'New Aircraft and Equipment'
3. Click 'New Aircraft and Equipment' on the left menu labeled 'Common Actions'
4. In the 'New Aircraft or Equipment' field, enter 'MSN6424'
5. In the 'Serial' field and 'Registratrion' field, enter 'MSN6424' 
6. In the 'Part Number' field, click the arrow, then click 'Select Value'. Search for 'A321' and click 'A321'
7. In the 'Model' field, click the magnifying glass and select 'A321'
8. In the 'Aircraft and Equipment Status' field, click the magnifying glass and select 'OPERATING'
9. Scroll down to the 'Date Information' section. In the 'Date of Transfer of Title' field, input '01/01/00'
10. Click the Save button in the top right
11. Click 'Change Status' on the left menu labeled 'Common Actions'. Select 'Active Status' and click 'OK'
12. Click 'Create Aircraft or Equipment' on the left menu labeled 'Create Aircraft or Equipment'
13. Repeat the process for the following MSN IDs

     - 'MSN4535' (Model: A319)
     - 'MSN5611' (Model: A320)
     - 'MSN5613' (Model: A320)

NOTE: If you are using newly downloaded data, you will need to create a new column labeled 'Aircraft 1_MSN ID' and add in your own MSN ID values. The format should be the same as above 'MSN####'. A single MSN ID can be used for many different ASRS entries, but you must ensure that each MSN ID is only associted with a single Make/Model. For example, if you have 1 existing ASRS entry with Make Model of A320, and you add an MSN ID of 'MSN1000', you must ensure that MSN1000 is only used for other ASRS entries with A320 and no other make/model.

## Primary Problem
This will describe how to create new event types in Maximo.
  - Source variable from our ASRS dataset is 'Assessments_Primary Problem'
  - Target variable in Maximo is ''

Step-by-Step Walkthrough:
1. Log into IBM Maximo and find the Search tab in the top left 
2. Search for 'Domains' and click on 'Domains'
3. In the 'Domain' field, search for 'PLUSAEVENTTYPE' and click the slider icon on the left-side of the resulting record
4. Click the (+) icon on the top right of the table
5. In the 'Internal Value' field, enter 'OPERATIONAL'
6. In the 'Value' field, enter 'AIRCRAFT'. Ensure this is all caps

NOTE: If you are using newly downloaded data, you will need to ensure that the values for 'Assessments_Primary Problem' are in all caps. You can accomplish this via the UPPER() function in Excel.
