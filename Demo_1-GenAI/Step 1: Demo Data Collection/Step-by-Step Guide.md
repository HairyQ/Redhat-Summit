# Step 1: Demo Data Collection
## Data Description
This data represents a series of descriptive reports accounting events that occurred during a passenger airplane's flight/takeoff/landing/taxi/etc. These events could be simple human errors, equipment malfucntions, weather occurrences, etc. They are relatively structured with a set of variables that are mostly nullable, but most importantly they consist of 1-2 Narratives that are user-submitted, often lengthy, descriptions of the event. The initial data set will include over 120 variables, but after our data curation in Step 5, we will focus on only 13:
    - ACN: Unique Identifier for the report auto-generated by ASRS database
    - Date Time: Date and Time of the report. This data will need to be transformed to meet your desired endpoint format.
    - MSN ID: New variable added in the pre-steps of the demo (see Step 1b-4 below)
    - Aircraft Component: The component of the aircraft that was impacted by the event
    - Person 1_Function: The role of the person who submitted the record
    - State Reference: The 2-character state reference code where the event occurred
    - Flight Phase: The phase of the flight (e.g. Cruise, Initial Climb) when the event occurred
    - Primary Problem: The high-level cause of the event (e.g. Aircraft, Environment, Human Error)
    - Anomaly: The root cause of the event (e.g. Aircraft Equipment Problem, Airspace Violation)
    - Result: The remediation action taken (e.g. Diverted, Air Traffic Control Assistance)
    - Narrative(s): 1-2 user-submitted text narratives of the event. These will be removed and auto-summarized via Llama GenAI

    
### 1a. Download New Data
1. Navigate to NASA ASRS Database to download data.
    - LINK: https://akama.arc.nasa.gov/ASRSDBOnline/QueryWizard_Filter.aspx
2. Select appropriate filters 
    - Date Range: Jan 2014 - Dec 2024
    - Make/Model: All Airbus models
    - Mission: Passenger
3. Click Run Search > Export Excel File
### 1b. Transform and Supplement Data
1. Transform date variable to desired format
2. Consolidate Parent and Child Headers into single row
3. Remove empty rows (particularly Row 3)
4. Add 'MSNID' Variable
      - This will act as a dummy unique identifier (Manufacturer Serial Number) for the aircraft associated with each event.
      - MSNID format should be 'MSN####' where each '####' is a unique 4-digit identifier. These will have to be manually inputted into IBM Maximo, so be sure to only include a limited amount (e.g. 10 unique MSN IDs).
      - Ensure that each MSNID is only associated with a single 'Make Model Name' for consistency purposes. For example, if you have MSN1234 associated with an Event with Make Model of A320, be sure that you do not have another event tagged with MSN1234 of a different Make Model (e.g. A200).
5. Convert Aircraft Component to appropriate format
       - In Excel, create a new column at BA and use the below function to edit column AZ (Aircraft 1_Component)
              - =UPPER(LEFT(AZ4,3))
6. Convert Person 1_Function column (CP) to uppercase using UPPER Excel function
